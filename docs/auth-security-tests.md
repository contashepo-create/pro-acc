## ثغرة أمنية اكتشفتها الاختبارات وأُصلحت

**تعداد الحسابات (User Enumeration) في `forgot-password`:**
كانت الاستجابة تختلف بحسب وجود الحساب:
- حساب غير موجود → «إذا كان البريد الإلكتروني مسجلاً، ستتلقى رابط إعادة التعيين»
- حساب موجود + أُرسل البريد → «تم إرسال رابط إعادة التعيين إلى بريدك الإلكتروني»

هذا يجعل من السهل تخمين الحسابات المسجلة. **تم الإصلاح**: أُعيدت نفس الرسالة العامة في الحالتين (لا فرق في نص الاستجابة).
