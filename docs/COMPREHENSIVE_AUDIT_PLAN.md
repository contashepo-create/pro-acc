## قواعد الإنهاء

- لا يُعتبر نجاح اختبار محدود أو وجود commit دليلاً كافياً بمفرده.
- كل عملية تمس المال أو المخزون أو الالتزامات يجب أن تكون معزولة بالشركة، متوازنة محاسبياً، ذرية أو قابلة للعكس، وقابلة للتدقيق.
- يجب تمييز أربع حالات لكل نطاق: **مراجع كودياً**، **مختبر بوحدات/مسارات**، **مختبر على PostgreSQL حي**، **مختبر E2E**.
- لا يجوز وصف اختبار بأنه ناجح إذا تعذر تشغيله بسبب البيئة؛ يسجل كـ **محجوب** مع السبب.
- الأعداد أدناه تُعاد آلياً عند كل إغلاق نهائي، ولا تعتمد الأرقام التاريخية القديمة.
