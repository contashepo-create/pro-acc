# خطة التدقيق والتنفيذ الشامل

> وثيقة عمل داخلية لتتبع التنفيذ. لا تُعد المربعات مكتملة إلا بعد مراجعة الكود، إصلاح المخاطر المكتشفة، إضافة/تحديث الاختبارات، وتشغيل الاختبارات ذات الصلة.

## قواعد الإنهاء

- لا يُعتبر `commit` أو `push` أو نجاح اختبار محدود نهاية للعمل.
- لا يتم الدفع النهائي إلا بعد مراجعة جميع الأقسام أدناه وتشغيل الاختبارات الشاملة وTypeScript وlint ومراجعة فرق الملفات.
- كل عملية تمس المال أو المخزون أو الالتزامات يجب أن تكون معزولة بالشركة، متوازنة محاسبياً، وقابلة للتدقيق أو العكس.
